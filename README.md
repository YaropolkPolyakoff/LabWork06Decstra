# Алгоритм Дейкстры - Поиск кратчайшего пути

## Описание

Графическое приложение Windows Forms на C#, реализующее поиск кратчайшего пути на графе с помощью алгоритма Дейкстры.

## Возможности

- **Стандартный граф**: По умолчанию загружается граф с 6 вершинами и 11 рёбрами
- **Визуализация графа**: Интерактивное отображение вершин и рёбер
- **Управление вершинами**: Добавление и удаление вершин
- **Управление рёбрами**: Добавление и удаление рёбер с указанием веса
- **Поиск кратчайшего пути**: Нахождение кратчайшего пути между двумя вершинами
- **Поддержка несвязанных графов**: Корректная обработка несвязанных компонент
- **Перемещение вершин**: Возможность перетаскивать вершины мышью для удобного расположения

## Требования

- Visual Studio 2015 или выше
- .NET Framework 4.7.2 или выше
- Windows 7 или выше

## Установка и запуск

### Способ 1: Открытие проекта в Visual Studio

1. Откройте файл `DijkstraApp.csproj` в Visual Studio
2. Нажмите F5 или кнопку "Запуск" для компиляции и запуска приложения

### Способ 2: Компиляция из командной строки

```bash
msbuild DijkstraApp.csproj /p:Configuration=Release
cd bin\Release
DijkstraApp.exe
```

## Использование

### Управление вершинами

1. Введите ID вершины в поле "ID вершины"
2. Нажмите "Добавить вершину" для создания новой вершины
3. Нажмите "Удалить вершину" для удаления существующей вершины

### Управление рёбрами

1. Введите ID начальной вершины в поле "Из"
2. Введите ID конечной вершины в поле "В"
3. Введите вес ребра в поле "Вес" (только положительные числа)
4. Нажмите "Добавить ребро" для создания связи между вершинами
5. Нажмите "Удалить ребро" для удаления связи

### Поиск кратчайшего пути

1. Выберите начальную вершину из выпадающего списка "Начальная"
2. Выберите конечную вершину из выпадающего списка "Конечная"
3. Нажмите кнопку "Найти путь"
4. Результат будет отображён в поле "Результат"
5. Кратчайший путь будет выделен красным цветом на графе, а вершины на пути будут подсвечены зелёным

### Дополнительные функции

- **Очистить граф**: Удаляет все вершины и рёбра
- **Загрузить стандартный граф**: Восстанавливает граф по умолчанию
- **Перемещение вершин**: Зажмите левую кнопку мыши на вершине и перетащите её в нужное место

## Технические детали

- **Алгоритм**: Реализован классический алгоритм Дейкстры для поиска кратчайшего пути
- **Структура данных**: Граф представлен в виде списка смежности (adjacency list)
- **Тип графа**: Неориентированный взвешенный граф
